# Re:Earth CMS API

Client libraries for the [Re:Earth CMS](https://github.com/reearth/reearth-cms) API, for Go and TypeScript/JavaScript. Both are built on the OpenAPI schema of the Integration API, copied from reearth-cms.

## Libraries

| Language | Package | Install | Docs |
|---|---|---|---|
| [Go](go) | `github.com/reearth/reearth-cms-api/go` | `go get github.com/reearth/reearth-cms-api/go` | [pkg.go.dev](https://pkg.go.dev/github.com/reearth/reearth-cms-api/go) |
| [TypeScript/JavaScript](ts) | [`@reearth/cms-api`](https://www.npmjs.com/package/@reearth/cms-api) | `npm install @reearth/cms-api` | [API reference](https://reearth.github.io/reearth-cms-api/) |
